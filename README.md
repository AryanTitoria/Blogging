 Blogging (MERN + GridFS + JWT)

A full-stack blogging application built with React, Node.js, Express, and MongoDB (GridFS).
It supports user authentication, creating/editing blog posts, category filtering, and image uploads.

FOR setup guide go to "SETUP.md" in files

Deployed using:

🔹 Frontend: Vercel

🔹 Backend: Railway

🔹 Database: MongoDB Atlas

🔹 Image Storage: GridFS

🚀 Features
✔ User Authentication

Secure JWT-based login & signup

Access Tokens & Refresh Tokens

✔ Blog Management

Create, read, update, delete posts

Categories support

Rich text descriptions

Auto-timestamped posts

✔ Image Uploads (GridFS)

Store images securely in MongoDB using GridFSBucket

Auto URL generation

Handles large files

Works on cloud hosting

✔ Responsive UI

Built with React + Material UI

Mobile-friendly layout

Clean, minimal design

✔ Full Production Setup

Environment-driven config

Secure API keys

CORS correctly configured

Works on Vercel + Railway seamlessly
